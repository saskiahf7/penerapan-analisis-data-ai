## 📋 Pembahasan dan Implementasi:

* **Pemahaman Bisnis (Business Understanding)**: Menerjemahkan permasalahan manajemen terkait kenaikan pendapatan (*sales revenue*) yang dibarengi dengan penurunan laba bersih (*net profit*) sebesar 14% serta lonjakan piutang usaha (*accounts receivable*) hingga 300%.
* **Pengolahan Data (Data Preparation)**: Menyiapkan dataset transaksi simulasi, mengatasi anomali dan duplikasi data, membersihkan nilai kosong, serta memastikan tidak terjadi *Data Leakage* dengan mengisolasi fitur aktual pembayaran.
* **Analisis Data & Pemodelan (Modeling)**: Melakukan eksplorasi menggunakan empat level analitik (Deskriptif, Diagnostik, Prediktif, dan Preskriptif) serta membandingkan algoritma *Machine Learning* (seperti *Logistic Regression* dan *Random Forest*) untuk mendeteksi potensi *Late Payment*.
* **Evaluasi & Penggunaan AI (Evaluation & GenAI)**: Mengevaluasi performa akurasi model serta memanfaatkan *Generative AI* secara bijak sebagai asisten interpretasi data dengan tetap berpijak pada verifikasi manusia (*human-in-the-loop*).
* **Pengembangan Lanjutan (Deployment)**: Mengemas seluruh hasil analisis dan model prediksi ke dalam dashboard web interaktif berbasis web untuk membantu pengambilan keputusan strategis manajemen.
